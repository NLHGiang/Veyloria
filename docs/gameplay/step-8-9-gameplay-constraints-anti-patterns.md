# 8.9 — Gameplay Constraints & Anti-Patterns

## Purpose

8.9 defines the guardrails that protect Veyloria from becoming a different game as new systems are introduced.

> **Every core mechanic must protect Player Fantasy, Memory ≠ Truth, and The World Remembers.**

## Primary Constraint

Veyloria must not become a system collection.

A new core system should directly support one or more:
1. Explore
2. Notice & Investigate
3. Interact & Change
4. Memory & Contradiction
5. Consequence & World Remembers

If a system does none of these, it should not enter the core by default.

## Major Anti-Patterns

### Generic Gameplay Inflation
Do not add mechanics merely because they are individually fun or conventional.

> **More systems do not automatically mean more gameplay.**

### Memory as Cosmetic Theme
Memory must not be reduced to dialogue flavor, visual effects, lore text, collectibles, or flashbacks.

> **Memory is world logic, not decoration.**

Memory should produce gameplay consequences such as NPC behavior, relationships, locations, objects, quest availability, world state, future interactions, or interpretation.

### Exposition Dump
Core mystery should not normally be solved by an NPC or cutscene explaining everything.

Preferred information hierarchy:

> **INFER > DISCOVER > SHOW > TELL**

### Quest Marker Solves the Mystery
Objectives can be clear without making the mystery clear.

> **Objective clarity ≠ narrative certainty.**

### Player Agency Without Consequence
Significant choices should leave meaningful footprints in memory, relationships, world state, future quests, information availability, or later interpretation.

> **Not every action needs a branch. Every meaningful action needs a trace.**

### Fake Consequence
Consequences should be encountered rather than merely announced.

### Binary Morality
Do not reduce Veyloria's ambiguity to Good/Evil meters.

> **Ambiguous consequence > moral score**

### Memory Meter
Memory is not inherently a resource. Avoid treating the core memory model as a percentage, bar, or generic collectible currency.

Prefer qualitative memory relationships.

### Lore Inventory
Do not turn mystery into collecting lore fragments for completion. Evidence should have interpretive value.

### Revisit Without New Meaning
Returning to a place should have the potential to reveal new evidence, changed state, changed behavior, changed interpretation, new access, contradiction, or consequence.

> **The same place should be capable of meaning something different later.**

### Resetting the World
Meaningful world states should persist long enough for players to experience their consequences. Resets must not casually violate trust in persistence.

### Infinite Consequence Explosion
Not every action needs a permanent branch.

- Minor: small reaction or dialogue/object change.
- Significant: relationship, quest, or location change.
- Major: act progression, recontextualization, or persistent world consequence.

### Power Progression Dominates Understanding
Primary progression remains:

> **Understanding > Power**

Prefer unlocks through knowledge, recognition, interpretation, relationships, access, perception, and understanding.

### Grinding to Solve Narrative Problems
Do not require farming, killing, collecting, or currency grinding to understand narrative mysteries.

### Combat as Default Solution
If combat exists, it must have a meaningful gameplay or narrative role. It must not automatically solve memory, relationship, investigation, or social problems.

### Cozy Activities Become the Main Game
Farming, fishing, cooking, decorating, collecting, and routines may provide rhythm and breathing space, but must not replace the mystery.

Core identity remains:

> **Explore → Notice → Investigate → Act → Consequence → Remember**

### Checklist Gameplay
Avoid sessions that are primarily checklist → reward.

Prefer:

> **Problem → Action → Change → Question**

### Reward Replaces Curiosity
Material rewards may exist, but investigation should primarily reward information, changed understanding, new possibilities, world response, or new questions.

### Pet as Quest Marker
The pet should suggest attention, not solve investigation.

### Mystery Becomes Obscurity
Mystery must not become unfair confusion.

> **Meaning may be ambiguous; interaction should not be arbitrarily ambiguous.**

### Failure Has No Memory
Failure is also action. Wrong accusations, ignored clues, or incorrect interpretations may create NPC memory, relationship changes, missed opportunities, new contradictions, future evidence, or alternate interpretations.

> **Failure can be narrative information.**

### Perfect Information UI
Do not expose canonical truth when the player is supposed to discover it.

UI should primarily represent:

> **what the player knows**

rather than:

> **what the world knows.**

### Omniscient Journal
The journal should not automatically become an authoritative database of truth. It may distinguish evidence, observation, player conclusion, unresolved question, and contradiction.

### Cutscene Solves Gameplay
Cutscenes should support canonical events, emotional transitions, pacing, and events that cannot be meaningfully gameplayized.

They should not bypass:

> **Observe → Investigate → Choose → Consequence**

### Narrative Orphans
Significant gameplay actions should have the potential to create a narrative footprint.

> **Gameplay happened, but story never remembers it** is an anti-pattern.

### Story Dictates Every Action
Screenplay should define intent, situation, and canonical truth. Gameplay should define player action, interpretation, and expression.

### Arbitrary Canon
Maintain separation between Canonical Truth, Character Memory, Player Memory, and Player Interpretation.

World memories may be wrong, but the underlying world model must remain coherent.

### Everything Is About Memory
Memory is underlying world logic, not a constant dialogue topic. Ordinary activities and quiet moments are necessary so memory-driven changes retain contrast and impact.

### Constant Mystery Fatigue
Not every session needs a major revelation. Content should include discovery, action, consequence, quiet moments, relationships, ordinary life, unresolved questions, and occasional major recontextualization.

### Every Question Must Be Answered Immediately
A session may end with:

> **Answer → New Question**

or:

> **Partial Answer → Stronger Question**

Unresolved questions are valid content.

### Progression Through Content Quantity
Progression should be felt through what the player now understands, recognizes, accesses, changes, or remembers differently, not merely through counts of quests, areas, items, NPCs, or collectibles.

### Mechanic Before Meaning
Correct order:

> **Theme / Player Need → Gameplay Problem → Mechanic → Feedback → Consequence**

Do not start with a mechanic and search for a place to insert it.

## Gameplay Design Gate

Every new core mechanic should answer:

1. Which Player Fantasy does it serve?
2. Does it reinforce The World Remembers?
3. What does the player actually do?
4. What must the player notice?
5. Where is player agency?
6. Can it create a narrative footprint?
7. Can it create contradiction or recontextualization?
8. Does it improve understanding rather than merely power?
9. Does it fit a meaningful 10–15 minute session beat?
10. Does it add meaningful experience rather than generic complexity?

If a mechanic fails several of these tests, it should not enter core gameplay.

## Priority Rule

When design goals conflict, prioritize:

1. Player Fantasy
2. The World Remembers
3. Player Agency
4. Memory ≠ Truth
5. Meaningful Consequence
6. Understanding Progression
7. Session Clarity
8. Systemic Depth
9. Content Quantity

> **A small identity-strong system is better than a large generic system.**

## Anti-Pattern Test

Ask:

> **If the Veyloria story were removed, would this mechanic still look exactly the same?**

> **Could this mechanic exist in almost any cozy adventure game?**

> **Does the world remember what the player did through this mechanic?**

If the answers reveal that the mechanic is generic and leaves no meaningful trace, it should not be treated as a core identity system.

## Locked Direction

### CORE CONSTRAINT
> **Every core mechanic must reinforce the player's relationship with a world that remembers.**

### PRIMARY PROGRESSION
> **Understanding > Power**

### MYSTERY RULE
> **Ambiguity is allowed. Unfair obscurity is not.**

### CHOICE RULE
> **Significant choices must leave traces.**

### CONSEQUENCE RULE
> **Consequences should be experienced, not merely announced.**

### MEMORY RULE
> **Memory is world logic, not a cosmetic theme or collectible resource.**

### SYSTEM RULE
> **No system enters the core merely because it is fun in isolation.**

### STORY RULE
> **Important story information should become playable whenever possible.**

### REVISIT RULE
> **Returning to a place should have the potential to change its meaning.**

### PROGRESSION RULE
> **The player should become better at understanding Veyloria, not merely stronger inside it.**

### IDENTITY RULE
> **Veyloria must not become a collection of generic gameplay systems surrounding a memory story.**

## North Star

> **Protect the mystery. Protect the agency. Protect the consequence. Protect the memory.**

> **Do not build mechanics that make the game bigger while making Veyloria smaller.**
